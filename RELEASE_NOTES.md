# Aerial Universal 1.49

**This is an unofficial derivative build based on [Aerial by pengchujin](https://github.com/pengchujin/aerial-tv). It is not an original or upstream release.**

## Files

- `aerial-universal-1.49-standard.apk` — Android HOME launcher variant.
- `aerial-universal-1.49-guard.apk` — variant without a HOME intent filter for firmware that blocks launcher packages.

Both APKs use the same package name and cannot be installed side by side. Choose one. If unsure, try Standard first.

## Changes in this custom build

- Layout that adapts to the available TV display area, with clock, date, weather, network/settings controls, and a five-item dock.
- Refined dock sizing and focus spacing for TV remote navigation.
- Flip-clock screensaver and configurable inactivity-to-screensaver and screensaver-to-standby delays.
- Includes upstream Aerial wallpaper and screensaver functions.

## Compatibility

Primary test device: TCL Q10G Pro. Other Android TV / Google TV devices have not all been verified. Vendor firmware may limit launcher selection, background behavior, screensaver scheduling, or standby. Samsung Tizen, LG webOS and VIDAA are not Android TV platforms and cannot install this APK.
